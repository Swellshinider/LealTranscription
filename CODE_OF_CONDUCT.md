# Code of conduct

Be respectful, consider differing viewpoints, give constructive feedback, and
focus on helping the project and its users.

Harassment, discrimination, personal attacks, intimidation, unwanted sexual
attention, and publishing another person's private information are unacceptable.
These expectations apply in project spaces and when representing the project.

Maintainers may remove or reject contributions and interactions that violate
this policy, and restrict participation when necessary.

Do not post sensitive conduct reports in public issues. Contact a maintainer
through a private channel they have provided; this project does not publish a
dedicated conduct-reporting channel. Report security vulnerabilities through
[SECURITY.md](SECURITY.md).

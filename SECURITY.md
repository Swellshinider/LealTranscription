# Security policy

## Reporting a vulnerability

Do not report vulnerabilities or share sensitive recordings, transcripts, or
credentials in public issues or pull requests.

Use [GitHub private vulnerability reporting](https://github.com/Swellshinider/LealTranscription/security/advisories/new).
If the form is unavailable, contact a maintainer through a private channel they
have provided. This project does not publish a dedicated alternate security
contact or a response-time guarantee.

Include the affected commit or version, operating system, reproduction steps,
impact, and any safe mitigation. Use synthetic input where possible and allow
time for investigation before public disclosure.

## Supported versions

There is no formal version-support matrix. Include the exact commit or version
you tested so maintainers can establish the affected scope.
